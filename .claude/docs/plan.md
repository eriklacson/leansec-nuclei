# Implementation Plan: Local Container Rebuild (v0.2)

Source spec: `.claude/docs/scope.md` + `.claude/docs/project.yaml` (`local-container-rebuild`)
Architecture: `.claude/docs/ADR-007-python-in-container.md` (to be committed under `decisions/`)
Status: PLAN — awaiting architect approval before IMPLEMENT.

---

## Goal in one line

Rebuild `docker/Dockerfile.local` and `docker/entrypoint.sh` so local CLI and local Docker produce **byte-identical outputs** at identical paths, with `profiles.yaml` as the single source of truth for scan logic. Cloud Dockerfile is explicitly deferred.

## Architectural shift being applied

ADR-007 reverses the seed document's locked decision "container entrypoint is bash, no YAML parsing." New split:

- **`docker/entrypoint.sh`** — thin bash wrapper. Validates env, dispatches cloud I/O (gcp/aws/azure stubs present, only `local` exercised), invokes `python -m scanner.scan ${CLIENT}`. Does not parse YAML, does not loop over profiles, does not hardcode nuclei flags.
- **`scanner/scan.py`** — unchanged. Single source of truth for scan execution across local CLI and container modes.

This eliminates the `profiles.yaml` ↔ `entrypoint.sh` drift surface structurally, not by discipline.

## Defects this plan fixes

1. `COPY ../scanner/profiles/` in `Dockerfile.local` is invalid Docker syntax — fails under any build context. Fixed by switching build context to repo root and rewriting COPY paths.
2. `entrypoint.sh` writes JSONL filenames (`identity_`, `transport_`, `owasp_top10_`, `transport_`) that diverge from canonical profile names in `profiles.yaml` (`identity_remote_access`, `owasp_top10_core`, `transport_security`). Fixed by deleting all hardcoded nuclei invocations and delegating to `scan.py`, which derives filenames from `profiles.yaml` keys.
3. Container produces only raw JSONL; local CLI produces JSONL **plus** consolidated `result-YYYY-MM-DD.json`. Fixed by invoking `scan.py`, which produces both.
4. No canonical `docker run` invocation documented. Fixed by adding a Local Docker section to README parallel to Local CLI.

### Step 4 — Rewrite `docker/Dockerfile.local` (~20 min)

Target shape (concrete sketch — final exact text TBD during IMPLEMENT):

```dockerfile
# Generated by Claude Code

# Base aligned with planned vmctl image; same base for both containers in the repo.
FROM python:3.12-slim

ARG NUCLEI_VERSION=v3.4.10

# Minimal OS deps: curl for nuclei download, ca-certificates for TLS, unzip for archive.
RUN apt-get update \
 && apt-get install -y --no-install-recommends curl ca-certificates unzip \
 && rm -rf /var/lib/apt/lists/*

# Install Nuclei at pinned version (architecture: linux_amd64; revisit for arm64 if needed).
RUN curl -sSL -o /tmp/nuclei.zip \
      "https://github.com/projectdiscovery/nuclei/releases/download/${NUCLEI_VERSION}/nuclei_${NUCLEI_VERSION#v}_linux_amd64.zip" \
 && unzip /tmp/nuclei.zip -d /usr/local/bin/ \
 && chmod +x /usr/local/bin/nuclei \
 && rm /tmp/nuclei.zip

# Runtime python deps: pyyaml only. No Poetry, no cloud SDKs.
RUN pip install --no-cache-dir pyyaml==6.0.2

WORKDIR /app

# Build context = repo root; scanner/ copied wholesale (profiles.yaml baked in).
COPY scanner/ /app/scanner/
COPY docker/entrypoint.sh /app/entrypoint.sh
RUN chmod +x /app/entrypoint.sh

# Default to local mode — overridable at runtime.
ENV CLOUD_PROVIDER=local \
    UPDATE_TEMPLATES=true \
    PYTHONUNBUFFERED=1

VOLUME ["/app/deployments", "/app/results"]

ENTRYPOINT ["/app/entrypoint.sh"]
```

### Step 5 — Rewrite `docker/entrypoint.sh` (~30 min)

Target shape:

```bash
#!/bin/bash
# Generated by Claude Code
# See decisions/ADR-007-python-in-container.md for the architectural shift
# (bash for cloud I/O dispatch, scan.py for scan execution + YAML parsing).
set -euo pipefail

# ─── env validation ───
# CLIENT must match a directory under deployments/<client>/.
: "${CLIENT:?CLIENT env var is required (matches deployments/<client>/)}"
CLOUD_PROVIDER="${CLOUD_PROVIDER:-local}"
UPDATE_TEMPLATES="${UPDATE_TEMPLATES:-true}"

case "${CLOUD_PROVIDER}" in
  local|gcp|aws|azure) ;;
  *) echo "Unsupported CLOUD_PROVIDER: ${CLOUD_PROVIDER}" >&2; exit 1 ;;
esac

# Cloud modes need bucket env; fail fast.
if [ "${CLOUD_PROVIDER}" != "local" ]; then
  : "${CONFIG_BUCKET:?CONFIG_BUCKET is required when CLOUD_PROVIDER=${CLOUD_PROVIDER}}"
  : "${RESULTS_BUCKET:?RESULTS_BUCKET is required when CLOUD_PROVIDER=${CLOUD_PROVIDER}}"
fi

# Local mode validates the deployment dir exists; cloud modes fetch it.
if [ "${CLOUD_PROVIDER}" = "local" ]; then
  if [ ! -d "/app/deployments/${CLIENT}" ]; then
    echo "Error: /app/deployments/${CLIENT} not found (mount deployments/ at /app/deployments)" >&2
    exit 1
  fi
fi

TARGETS_PATH="${TARGETS_PATH:-targets/targets.txt}"

# ─── cloud I/O dispatch ───
# download_config: fetch only targets.txt (profiles.yaml is baked into the image).
download_config() {
  case "${CLOUD_PROVIDER}" in
    local)
      : ;;  # volume mount provides /app/deployments/${CLIENT}/targets.txt
    gcp)
      mkdir -p "/app/deployments/${CLIENT}"
      gcloud storage cp "${CONFIG_BUCKET}/${TARGETS_PATH}" \
        "/app/deployments/${CLIENT}/targets.txt"
      ;;
    aws)
      mkdir -p "/app/deployments/${CLIENT}"
      aws s3 cp "s3://${CONFIG_BUCKET}/${TARGETS_PATH}" \
        "/app/deployments/${CLIENT}/targets.txt"
      ;;
    azure)
      mkdir -p "/app/deployments/${CLIENT}"
      az storage blob download --container "${CONFIG_BUCKET}" \
        --name "${TARGETS_PATH}" \
        --file "/app/deployments/${CLIENT}/targets.txt"
      ;;
  esac
}

# upload_results: must upload BOTH raw JSONL and consolidated normalized JSON.
upload_results() {
  local results_dir="/app/results/${CLIENT}"
  case "${CLOUD_PROVIDER}" in
    local)
      : ;;  # volume mount writes results in place
    gcp)
      gcloud storage cp -r "${results_dir}/*" "${RESULTS_BUCKET}/${CLIENT}/"
      ;;
    aws)
      aws s3 cp "${results_dir}/" "s3://${RESULTS_BUCKET}/${CLIENT}/" \
        --recursive --exclude "*" --include "*.jsonl" --include "result-*.json"
      ;;
    azure)
      # iterate over both jsonl and result-*.json in YYYY-MM subdirs
      find "${results_dir}" -type f \( -name "*.jsonl" -o -name "result-*.json" \) | while read -r f; do
        relpath="${f#${results_dir}/}"
        az storage blob upload --container "${RESULTS_BUCKET}" \
          --name "${CLIENT}/${relpath}" --file "${f}"
      done
      ;;
  esac
}

# ─── run ───
download_config

if [ "${UPDATE_TEMPLATES}" = "true" ]; then
  nuclei -update-templates -silent
fi

# Single source of truth for scan execution. scan.py parses profiles.yaml,
# loops profiles, writes raw JSONL + consolidated result-YYYY-MM-DD.json.
python -m scanner.scan "${CLIENT}"

upload_results

echo "Scan complete for ${CLIENT} (provider=${CLOUD_PROVIDER})"
```

**Constraint checklist mapped from `project.yaml`:**
- [x] `#!/bin/bash`, `set -euo pipefail`
- [x] CLIENT validated; exits 1 with clear message if missing
- [x] CLOUD_PROVIDER validated against allowlist; exits 1 otherwise
- [x] No YAML parsing (parsing stays in `nuclei_helpers.py`)
- [x] No hardcoded nuclei flags
- [x] No bash loop over profiles — `scan.py` owns that
- [x] `download_config` fetches only `targets.txt`
- [x] `upload_results` covers `*.jsonl` AND `result-*.json`
- [x] Local mode: download/upload are no-ops (volume mounts do the work)
- [x] `UPDATE_TEMPLATES` env var with default `"true"`
- [x] Non-zero exit only when `scan.py` raises (per-profile failures stay inside `scan.py`)
- [x] Header references ADR-007

**Detail: how does `python -m scanner.scan` find the targets file?**
`scanner/scan.py:45` reads `REPO_ROOT/deployments/<client>/targets.txt`, where `REPO_ROOT` is the parent of `scanner/`. Inside the container, `WORKDIR=/app` and `scanner/` lives at `/app/scanner/`, so `REPO_ROOT` resolves to `/app/`. Volume mount `/app/deployments` (local mode) and `download_config` writing to `/app/deployments/${CLIENT}/targets.txt` (cloud modes) both align with that path. Output writes go to `/app/results/<client>/YYYY-MM/`, mounted at `/app/results` in local mode. **No code change to `scan.py` required.**

**Exit criteria:** all `entrypoint_validation` acceptance bars pass (see Step 7).

```python
# Generated by Claude Code

# Module-level Docker-availability skip — entire module skips if Docker is unreachable.
import pytest
import shutil
import subprocess
from pathlib import Path

NUCLEI_VERSION = "v3.4.10"  # mirrors ARG NUCLEI_VERSION in docker/Dockerfile.local
IMAGE_TAG = "leansecurity/nuclei-scanner:test-local"
REPO_ROOT = Path(__file__).resolve().parent.parent

if shutil.which("docker") is None:
    pytest.skip("docker not available", allow_module_level=True)
# Probe daemon reachability as well — `docker info` returns nonzero if daemon is down.
try:
    subprocess.run(["docker", "info"], check=True, capture_output=True, timeout=5)
except (subprocess.CalledProcessError, subprocess.TimeoutExpired, FileNotFoundError):
    pytest.skip("docker daemon not reachable", allow_module_level=True)


@pytest.fixture(scope="session")
def built_image():
    # Build once per session — repo root is the build context per ADR-007.
    subprocess.run(
        ["docker", "build",
         "-f", "docker/Dockerfile.local",
         "-t", IMAGE_TAG,
         "--build-arg", f"NUCLEI_VERSION={NUCLEI_VERSION}",
         "."],
        cwd=REPO_ROOT, check=True,
    )
    return IMAGE_TAG


def test_nuclei_version_pinned(built_image):
    # Image's nuclei must report the pinned version string.
    out = subprocess.run(
        ["docker", "run", "--rm", "--entrypoint", "nuclei", built_image, "-version"],
        capture_output=True, text=True, check=True,
    )
    assert NUCLEI_VERSION.lstrip("v") in (out.stdout + out.stderr)


def test_python_version(built_image):
    # python --version returns 3.12.x.
    out = subprocess.run(
        ["docker", "run", "--rm", "--entrypoint", "python", built_image, "--version"],
        capture_output=True, text=True, check=True,
    )
    assert "Python 3.12" in out.stdout + out.stderr


def test_profiles_yaml_baked_in(built_image):
    # profiles.yaml ships at /app/scanner/profiles/profiles.yaml and is valid YAML.
    out = subprocess.run(
        ["docker", "run", "--rm", "--entrypoint", "python", built_image,
         "-c", "import yaml,sys; yaml.safe_load(open('/app/scanner/profiles/profiles.yaml')); print('ok')"],
        capture_output=True, text=True, check=True,
    )
    assert "ok" in out.stdout


def test_missing_client_exits_nonzero(built_image):
    # No CLIENT env var → fail fast with clear error.
    out = subprocess.run(
        ["docker", "run", "--rm", built_image],
        capture_output=True, text=True,
    )
    assert out.returncode != 0
    assert "CLIENT" in (out.stdout + out.stderr)


def test_unsupported_cloud_provider_exits_nonzero(built_image):
    # CLOUD_PROVIDER outside allowlist → fail fast.
    out = subprocess.run(
        ["docker", "run", "--rm", "-e", "CLIENT=ghost", "-e", "CLOUD_PROVIDER=oracle", built_image],
        capture_output=True, text=True,
    )
    assert out.returncode != 0
    assert "Unsupported" in (out.stdout + out.stderr)


def test_missing_deployment_dir_exits_nonzero(built_image, tmp_path):
    # CLIENT references a deployment dir that doesn't exist on the mounted volume.
    deployments = tmp_path / "deployments"
    deployments.mkdir()
    out = subprocess.run(
        ["docker", "run", "--rm",
         "-e", "CLIENT=nonexistent",
         "-v", f"{deployments}:/app/deployments:ro",
         built_image],
        capture_output=True, text=True,
    )
    assert out.returncode != 0


def test_local_mode_produces_jsonl_and_normalized_json(built_image, tmp_path):
    # End-to-end: build a tmp deployments tree pointing at an unreachable target,
    # mount it, run the container, assert *.jsonl and result-*.json exist.
    client = "smoketest"
    deployments = tmp_path / "deployments" / client
    deployments.mkdir(parents=True)
    (deployments / "targets.txt").write_text("http://127.0.0.1:1\n")  # port 1 = unreachable, no network
    results = tmp_path / "results"
    results.mkdir()

    subprocess.run(
        ["docker", "run", "--rm",
         "-e", f"CLIENT={client}",
         "-e", "UPDATE_TEMPLATES=false",  # no outbound network in CI
         "-v", f"{tmp_path}/deployments:/app/deployments:ro",
         "-v", f"{results}:/app/results",
         built_image],
        check=True,
    )

    # Find any JSONL produced under results/<client>/YYYY-MM/.
    jsonl_files = list((results / client).rglob("*.jsonl"))
    normalized_files = list((results / client).rglob("result-*.json"))
    assert jsonl_files, "expected at least one *.jsonl"
    assert normalized_files, "expected result-YYYY-MM-DD.json"

    # Filenames use canonical profile names — no legacy stems.
    bad_stems = ("identity_2", "transport_2", "owasp_top10_2")  # year-month suffix proxy
    for f in jsonl_files:
        assert not any(f.name.startswith(b.split("_2")[0] + "_") and "_" not in f.stem.split("_2")[0] + "x" for b in bad_stems), (
            f"legacy filename detected: {f.name}"
        )
    # Direct check: any of the canonical names should appear.
    canonical = {"baseline_web", "patch_cve", "identity_remote_access",
                 "data_protection", "transport_security",
                 "owasp_top10_core", "vuln_monitoring"}
    seen = {f.stem.rsplit("_", 1)[0] for f in jsonl_files}
    assert seen & canonical, f"no canonical profile filenames found, saw: {seen}"
```
